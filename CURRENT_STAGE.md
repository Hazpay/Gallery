## 📝 Заметки и контекст
- Проект использует GitHub API для загрузки изображений или работает локально через file:// протокол
- Изображения организованы в коллекции: Flowers, Astronauts, Cards, Rus Text, Others
- Метаданные о размерах и материалах хранятся в CSV файле (materials-sizes.csv) и встроены в код
- Галерея поддерживает автоматическую презентацию после 35 секунд бездействия
- Реализован glassmorphism дизайн с поддержкой светлой/тёмной темы
- На мобильных устройствах: кнопки стрелок скрыты, работает swipe-навигация (порог 50px для распознавания свайпа)
- Swipe обрабатывается только для горизонтальных жестов (свайп влево = следующее, вправо = предыдущее)
- Кнопка информации: размер 56px (52px на мобильных), иконка "i" меняется на "!" при активации (через CSS ::before псевдоэлемент)
